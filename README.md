# Waffentrag-Trainer

Multiple-Choice-Trainer zur Vorbereitung auf die Prüfung Waffentragen (Schweiz).

- Alle 106 Fragen aus dem öffentlich publizierten Fragenkatalog des Bundesamts für Polizei fedpol (Stand 02.10.2019)
- Richtige Antworten gemäss Katalog, falsche Antwortvorschläge selbst ergänzt
- Fortschritt wird lokal im Browser gespeichert

Privates Lernprojekt, kein offizielles Angebot des Bundes. Massgebend sind die Unterlagen auf [fedpol.admin.ch](https://www.fedpol.admin.ch). Angaben ohne Gewähr.
